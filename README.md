

# 💰 Daily Expense Tracker

A simple yet powerful **personal finance web app** to track daily expenses with analytics, charts, and smart insights.

---

## ✨ Features

### 🧾 Expense Management

* Add daily expenses with title, category, amount, and date
* Edit and delete transactions
* Real-time updates

### 🔎 Smart Filtering

* Search expenses by keyword
* Filter by category
* Filter by month
* Filter by amount range

### 📊 Dashboard Analytics

* Total monthly spending
* Number of transactions
* Highest expense tracking
* Top spending category

### 📈 Data Visualization

* Pie chart (category distribution)
* Bar chart (daily spending trend)

### 🧠 Smart Insights

* Automatic spending analysis
* Budget behavior insights
* Category dominance detection

### 💾 Data Management

* LocalStorage persistence
* Export data to JSON (backup)
* Export data to CSV (Excel ready)
* Import data from backup file

### 🌙 UI/UX Features

* Responsive design (mobile friendly)
* Clean modern dashboard UI
* Smooth animations

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Modern UI + Responsive Design)
* Vanilla JavaScript
* Chart.js (for data visualization)
* LocalStorage API
