# Daily Expense Tracker

Aplikasi web sederhana untuk mencatat pengeluaran harian.

## Fitur
- Tambah pengeluaran
- Tampilkan daftar pengeluaran
- Hitung total pengeluaran
- Hapus pengeluaran
- Simpan data di localStorage

## Tools
- HTML
- CSS
- JavaScript
- localStorage

## Cara Menjalankan
1. Download project
2. Buka folder project
3. Jalankan file index.html di browser

## Rencana Pengembangan
- Edit pengeluaran
- Filter kategori
- Ringkasan per kategori
